# -Speech-And-Text-Jarvis-Assistant
Jarvis is a Python-based personal assistant that supports voice and text commands for automation. It uses Speech-to-Text (STT) and Text-to-Speech (TTS) technologies to interact naturally with users. With Jarvis, you can:  Control apps like Calculator, Notepad, Chrome, VS Code, and more  Perform web searches, open websites, and get quick answers
